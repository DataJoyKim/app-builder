활성화
{이름} 으로 경로변수를 받습니다. 경로변수는 Request Param 탭의 Path Variable 에 자동으로 추가됩니다.
인증/권한 검사는 워크플로우의 설정을 따릅니다.
각 값은 요청메시지ID 의 행에 매핑키(비우면 이름 그대로)로 담겨 워크플로우로 전달됩니다. 같은 요청메시지ID 로 모은 값들은 한 행에 함께 담깁니다.
Path Variable 경로의 {이름} 에서 자동으로 만들어집니다.
이름타입필수요청메시지ID매핑키설명
Request Param ?이름=값 으로 받는 값
이름타입필수기본값요청메시지ID매핑키설명
Request Header 헤더 이름은 대소문자를 구분하지 않습니다.
이름타입필수기본값요청메시지ID매핑키설명
GET 메소드는 Request Body 를 받을 수 없습니다. 본문이 필요하면 HTTP 메소드를 POST / PUT / DELETE 로 바꿔주세요.
OBJECT 는 본문이 요청메시지의 한 행, ARRAY 는 원소마다 한 행이 됩니다. OBJECT/ARRAY 필드에 요청메시지ID 를 적으면 그 필드가 별도 요청메시지가 되고, 비우면 상위 행에 중첩된 값으로 담깁니다.
본문을 받지 않습니다. 본문이 필요하면 본문 타입을 OBJECT 또는 ARRAY 로 선택해주세요.
본문 객체의 필드
필드명타입필수기본값요청메시지ID매핑키설명
요청 본문 예시 

                            

                        

                    

                


                
                

                    

                        

                        

                            

                                
                                
                            

                            

                                JSON 은 워크플로우 응답을 JSON 으로 돌려주고, 파일 다운로드는 응답메시지 한 행의 파일 데이터를 첨부파일로 내려줍니다.
                                워크플로우가 실패하면 응답유형과 상관없이 JSON 오류를 돌려줍니다.
                            

                        


                        
                        

                            

                                
                                

                                    응답메시지ID 를 지정하지 않으면 워크플로우 응답 전체(contents)를 그대로 돌려줍니다.
                                    지정하면 contents 에 그 메시지의 내용만 메시지ID 없이 담아 돌려줍니다.
                                    응답스키마(행의 필드)를 정의하면 정의한 필드만 그 타입으로 바꿔 돌려주고, 정의하지 않으면 행을 그대로 돌려줍니다.

                                    파일 메시지가 비어있으면 404, 내용을 읽을 수 없으면 500 JSON 오류를 돌려줍니다.
