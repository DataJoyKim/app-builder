파일 정의

기본 정보
파일 위치
#{파라미터} 로 요청메시지 값을 넣을 수 있습니다. 저장소경로 기준 상대경로이며 파일명까지 포함합니다.
파일 내용
byte[] 값은 인코딩과 상관없이 그대로 저장합니다.
Multipart: multipart/form-data 로 올라온 파일을 스트림 그대로 저장합니다. 파일내용 키는 쓰지않고, 업로드한 파일의 원본 파일명을 #{original_filename} 으로 파일경로에 쓸 수 있습니다.
업로드: 이 키의 값을 파일로 저장 / 조회: 이 키에 파일내용을 담아 응답
응답 항목
조회: filePath fileName fileSize contentType + 파일내용 키
업로드: filePath fileName fileSize contentType
삭제: filePath deleted
공통: resultCode(SUCCESS/FAILURE) message
