저장소 설정

저장소 DSL 배포 ?GitHub 저장소 브랜치의 {애플리케이션}/ 폴더 DSL 을 이 애플리케이션의 메타데이터 DB 에 반영(배포)합니다. 바뀐 메타데이터 중 원하는 것만 골라 배포할 수 있고, 고른 것만 반영했을 때 참조가 깨지면(예: 새 워크플로우가 고르지 않은 새 쿼리를 가리킴) 배포를 막습니다. 데이터소스, 워크플로우(쿼리/엔티티/REST 클라이언트/알림/메시지 프로세서), REST API, 스케줄러, 화면, 메뉴, 사이트, 공통코드가 대상이고, 회사·이미지·사용자·사용자그룹은 바뀌지 않습니다. 다른 애플리케이션 폴더를 고르면 그 DSL 을 이 애플리케이션에 배포합니다(예: 개발 → 운영).

고른 메타데이터를 저장소의 DSL 과 똑같이 맞추므로, 삭제로 표시된 것을 고르면 이 환경에서 삭제됩니다. 한 번에 반영되고, 하나라도 실패하면 아무것도 바뀌지 않습니다. 데이터베이스 비밀번호와 알림 제공자의 비밀값은 DSL 에 없으므로 이 환경의 값을 그대로 둡니다.
