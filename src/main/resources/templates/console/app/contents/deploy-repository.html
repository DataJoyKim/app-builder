GitHub 저장소 연동

애플리케이션 메타데이터를 DSL(JSON)로 커밋할 GitHub 저장소를 연결합니다. 연동한 뒤 Deploy > Commit 에서 비교하고 커밋할 수 있습니다.

확인 중

연동 설정

1저장소

DSL 을 커밋할 저장소입니다. 저장소 URL 을 붙여넣으면 자동으로 나눠 입력됩니다.

/

2브랜치

커밋이 올라갈 브랜치입니다. 없으면 첫 커밋 때 기본 브랜치에서 만듭니다.

운영 배포용 브랜치를 따로 두려면 deploy, release 처럼 별도 브랜치를 지정하세요.

3인증 토큰

저장소에 쓸 수 있는 Personal Access Token 입니다. 암호화해서 저장하며 다시 보여주지 않습니다.

토큰 저장됨 ••••••••••••
필요한 권한: Fine-grained 토큰은 Contents: Read and write, Classic 토큰은 repo. 변경 취소

연동 상태

  • 저장소
  • 브랜치
  • GitHub 계정
  • 마지막 저장
저장소 열기 Commit 으로
아직 연동된 저장소가 없습니다.
왼쪽에서 저장소와 토큰을 입력하고 저장하세요.

토큰 만들기

  1. GitHub 에서 Fine-grained 토큰 만들기 를 엽니다.
  2. Repository access 에서 연동할 저장소만 선택합니다.
  3. Permissions 의 Contents 를 Read and write 로 지정합니다.
  4. 만든 토큰을 복사해 왼쪽 인증 토큰 칸에 붙여넣고 저장합니다.
